## B) Release: post when it's live

Post this only once (1) Mojang has approved the app ID, (2) the installer is on the GitHub release, and
(3) swiftsmp.com/client is deployed.

```
# 🧡 SwiftClient is out!

The official **SwiftSMP** Minecraft client is here. Free, fast, and made for our server.

📥 **Download:** https://swiftsmp.com/client

⚡ More FPS out of the box (Sodium, Lithium, FerriteCore, EntityCulling & more)
🦅 SwiftClient capes that every SwiftClient player can see
🎛️ Right Shift menu: movable HUD (FPS, CPS, ping, coords, keystrokes, armor)
🙈 Hide the scoreboard, boss bar, titles and more
🔎 Zoom, auto sprint, bright mode
🧩 Add your own Fabric mods
🎮 One-click **Join SwiftSMP**
💬 Discord status: "Playing on swiftsmp.net"

**How to install**
1. Download and run `SwiftClient-Setup.exe`
2. If Windows shows "Windows protected your PC", click **More info → Run anyway**
3. Sign in with the Microsoft account that owns Minecraft: Java Edition
4. Press **Join SwiftSMP**. The first start downloads Minecraft, after that it's quick

🪟 Windows 10/11 · Minecraft 1.21 to 26.3 · SwiftClient updates itself
Questions or bugs? Ask in #support 💬
```
