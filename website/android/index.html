Setup

Playing in four steps

  1. Download the APK above. When Android asks, allow your browser to install apps.
  2. Sign in with Microsoft using the account that owns Minecraft: Java Edition.
  3. Pick a version and tap Play. SwiftClient installs Fabric, the SwiftClient mod, Fabric API and the phone performance pack, then downloads Minecraft and Java from Mojang.
  4. Join a server from the Servers tab, or play singleplayer. Pick your cape in Cloaks.

Questions

Android FAQ

Can you play Minecraft Java Edition on Android?

Yes. SwiftClient for Android runs the real Minecraft: Java Edition on your phone with your Microsoft account, touch controls and Fabric mods.

Do I need to own Java Edition?

Yes. Sign in with the Microsoft account that owns Minecraft: Java Edition. There is no offline mode.

Which phones work?

Android 8 or newer. A 64-bit phone with 4 GB of RAM or more is recommended; Minecraft 1.21.x runs best, 26.x needs a stronger phone.

How do I open the SwiftClient menu without a keyboard?

Add Right Shift as a button in Custom controls. Zoom (C) works the same way.

Is it open source?

Yes. It is built on Amethyst and PojavLauncher (LGPL-3.0); the source is on GitHub.
