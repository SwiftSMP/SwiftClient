Download SwiftClient

The free Minecraft: Java Edition client for Windows and Android. Pick how you want to install it.

RECOMMENDED

Microsoft Store

  1. Open the Store page and click Get.
  2. Launch SwiftClient and sign in with Microsoft.
  3. Press Play. Updates come through the Store.

Windows installer

  1. Download SwiftClient-Setup.exe.
  2. If SmartScreen appears: More info → Run anyway.
  3. SwiftClient updates itself from then on.
Download .exe

Android

  1. Download the APK and allow the install.
  2. Sign in with Microsoft.
  3. Pick a version and tap Play.
