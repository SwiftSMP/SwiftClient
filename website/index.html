Play Java Edition on your phone with SwiftClient

SwiftClient for Android is a full Minecraft: Java Edition launcher for your phone, tuned for it: Lithium, FerriteCore, ModernFix and EntityCulling, phone-friendly settings and a GC tuned against stutter.

  1. Install the APK and sign in with your Microsoft account.
  2. Pick a version and tap Play. Fabric, SwiftClient, Fabric API and a phone performance pack are set up for you.
  3. Join from the Servers tab straight into SwiftSMP, CyanRealms or ValenMC, and pick your cloak in Cloaks.
  4. Touch controls built in, plus keyboard, mouse and controller support. Add Right Shift as a button to open the SwiftClient menu.

Questions

FAQ

Is SwiftClient free?

Yes, completely. No ads and no paywalled features.

Do I need to own Minecraft?

Yes. SwiftClient signs in with your Microsoft account and launches the official Minecraft: Java Edition. There is no offline or cracked mode.

Store version or .exe?

Both are the same launcher. The Microsoft Store version installs and updates through the Store with no SmartScreen warning. The .exe updates itself from GitHub. They are separate installs with separate game folders.

Which Minecraft versions work?

Every release from 1.21 up to the newest one Fabric supports, currently 26.3. Pick the version on the Play screen.

Does it work on Android?

Yes. SwiftClient for Android is a full Java Edition launcher built on Amethyst/PojavLauncher, with touch controls, keyboard, mouse and controller support. Tap Install SwiftClient, pick a version and play. Performance depends on your phone; 1.21.x runs best. Discord presence is Windows-only.

Is it safe? Will I get banned?

SwiftClient is a Fabric mod set with visual and performance mods only. It has no PvP cheats. Servers that allow Fabric clients allow SwiftClient. Your password never touches SwiftClient.

Does it work on Mac or Linux?

Not yet. Windows 10/11 and Android only for now.
