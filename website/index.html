About

What is SwiftClient?

SwiftClient is a free Minecraft: Java Edition client and launcher for Windows 10/11 and Android. It installs the right Java runtime, Fabric loader and a tested performance mod pack for the Minecraft version you choose, so you can go from download to playing in a few clicks.

Every SwiftClient player sees your cape in game and on your elytra. You also get a HUD editor for FPS, CPS, ping and keystrokes, a Fabric mod manager that checks versions and conflicts, friends and direct messages, and one-click access to SwiftSMP and partner servers. There are no cheats, and sign-in happens on Microsoft's own page, so your password never touches SwiftClient.

Ready to play? Download SwiftClient for Windows, install the Minecraft Java Edition launcher for Android, or read the SwiftClient FAQ.

Questions

FAQ

Is SwiftClient free?

Yes, completely. No ads and no paywalled features.

Do I need to own Minecraft?

Yes. SwiftClient signs in with your Microsoft account and launches the official Minecraft: Java Edition. There is no offline or cracked mode.

Store version or .exe?

Both are the same launcher. The Microsoft Store version installs and updates through the Store with no SmartScreen warning. The .exe updates itself from GitHub. They are separate installs with separate game folders.

Which Minecraft versions work?

Every release from 1.21 up to the newest one Fabric supports, currently 26.3. Pick the version on the Play screen.

Does it work on Android?

Yes. SwiftClient for Android is a full Java Edition launcher with touch controls, a phone performance pack and one-tap SwiftClient setup. Discord presence is Windows-only.

Is it safe? Will I get banned?

SwiftClient adds visual and performance mods only and has no cheats, so servers that allow Fabric clients allow SwiftClient. You sign in on Microsoft's own page and your password never touches SwiftClient.

How do I get a cape?

Open the Cloaks tab in the launcher and pick one. Every SwiftClient player sees it in game and on your elytra.

What are the sky lyrics?

Press F7 in game and the words of whatever is playing on your PC (Spotify, Apple Music, YouTube Music or a browser) float in the sky in front of you, in time with the song, with a now-playing pill up top. On Android it reads the phone's active media session once you allow music access. Only the song title and artist are sent to the free LRCLIB lyrics service, and results are cached on your machine.

Can I use my own Fabric mods?

Yes. Drop Fabric mods into the Mods tab. SwiftClient checks each one for Minecraft version, conflicts and missing dependencies before you launch.

Do I need to install Java or Fabric?

No. SwiftClient installs the right Java runtime, Fabric loader and Fabric API for the Minecraft version you pick.

Mac or Linux?

Not yet. Windows 10/11 and Android for now.
